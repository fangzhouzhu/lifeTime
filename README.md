# LifeTime

An app that records your personal moments; you can use it to record your feelings or remind yourself to do something.

## 功能模块 (Features)

这个应用包含四个主要功能模块:

### 1. 备忘提醒 (Memo Reminder)
- 创建备忘录和提醒事项
- 图标: 通知铃铛
- 颜色: 蓝色

### 2. 重要日子 (Important Days)
- 记录生活中的重要日子和纪念日
- 图标: 日历笔记
- 颜色: 粉色

### 3. 人生碎片 (Life Fragments)
- 记录生活中的点点滴滴和珍贵时刻
- 图标: 照片库
- 颜色: 橙色

### 4. 待开发 (To Be Developed)
- 更多精彩功能即将上线
- 图标: 设置
- 颜色: 灰色

## 项目结构 (Project Structure)

```
lib/
├── main.dart                           # 应用入口
└── pages/
    ├── home_page.dart                  # 主页 - 四个功能模块按钮
    ├── memo_reminder_page.dart         # 备忘提醒页面
    ├── important_days_page.dart        # 重要日子页面
    ├── life_fragments_page.dart        # 人生碎片页面
    └── to_be_developed_page.dart       # 待开发页面
```

## 如何运行 (How to Run)

1. 确保已安装 Flutter SDK
2. 克隆仓库
3. 运行以下命令:

```bash
flutter pub get
flutter run
```
